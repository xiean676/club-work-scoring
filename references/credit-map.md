# 学分换算表

档位 × 质量系数 = 该产出物的实际学分。基础分值来自任务量的标准认定，与作者是谁无关。

这套表不另立分数体系：单次产出物的学分远低于成员年度学分上限（1 / 2 / 3），一件产出物不会把人推到干部档；年度累计时按同一张表累加。

## 各类型基础分值

| 类型码 | 产出物 | 基础分值 | 说明 |
|---|---|---|---|
| `plan` | 活动策划案 | 0.3 | 一份可提交审批的完整策划案 |
| `copy` | 宣传文案 | 0.1 | 一条推文或群通知 |
| `poster` | 活动海报 | 0.1 | 一张成品海报 |
| `ppt` | 宣讲 PPT（整套） | 0.2 | 一套完整 PPT |
| `ppt` | 宣讲 PPT（单页） | 0.05 | 单独评审的一页 |
| `contest` | 竞赛材料（校级/省级参赛） | 0.3 | 设计报告等全套 |
| `contest` | 竞赛材料（获省级一等奖以上） | 0.6 | 同上，附获奖加分 |

`--base` 参数可覆盖基础分值，用于同一类型不同工作量的情况（例如大场次策划案可 `--base 0.4`）。

## 档位系数

| 档位 | 系数 | 判定 |
|---|---|---|
| A | 1.5 | 均分 ≥ 4.0 且最低维度 ≥ 3，可直接交老师不用改 |
| B | 1.0 | 均分 2.5 - 4.0，或均分 ≥ 4.0 但最低维度 = 2 |
| C | 0.5 | 均分 < 2.5，或任一维度 = 1 |
| 退回 | 0 | 命中 P0 一票否决 |

判定顺序：先看否决 → 再看最低维度 = 1 → 再按均分。

## 换算示例

| 产出物 | 档位 | 基础分 | 系数 | 实得学分 |
|---|---|---|---|---|
| 活动策划案 | A | 0.3 | 1.5 | **0.45** |
| 活动策划案 | B | 0.3 | 1.0 | **0.30** |
| 活动策划案 | C | 0.3 | 0.5 | **0.15** |
| 活动策划案 | 退回 | 0.3 | — | **0** |
| 宣传文案 | A | 0.1 | 1.5 | 0.15 |
| 宣传文案 | C | 0.1 | 0.5 | 0.05 |
| 宣讲 PPT | A | 0.2 | 1.5 | 0.30 |
| 宣讲 PPT 单页 | B | 0.05 | 1.0 | 0.05 |
| 竞赛材料（省级一等奖） | A | 0.6 | 1.5 | 0.90 |
| 竞赛材料（省级一等奖） | C | 0.6 | 0.5 | 0.30 |

## 职务跟着学分走

年度累计达到阈值即授予对应职务，不再按"当干部"分配学分：

| 年度累计学分 | 职务 |
|---|---|
| < 0.5 | 普通成员 |
| 0.5 - 1.4 | 干事 |
| 1.5 - 2.4 | 部长 |
| ≥ 2.5 | 会长 |

累计学分按"已定档的产出物实得学分"累加，被退回的不计。一件产出物最多贡献 0.9 学分（竞赛材料 A 档），所以不会出现一个人单件产出直接当上会长——需要持续产出，这是设计意图。

## 跨族复核与学分的关系

- 主评与复核逐维比对，**任一分维差值 > 1 分** → 标记 `needs_human`，该产出物暂不定档，学分按 B 档（系数 1.0）暂挂，待人工复核后落定。
- 主评与复核档位相同但分维有差异（差值 ≤ 1）→ 自动取主评结果，正常发分。
- 复核模型否决而主评未否决 → 按退回处理，直接触发人工复核（这种情况说明预筛规则有盲区，要补充规则）。
